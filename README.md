# Projeto-BeeTech-Salve-as-Abelhas-
Projeto Integrador 2
Este projeto integra design arquitetônico, sustentabilidade e preservação da biodiversidade através do desenvolvimento de caixas-maquete personalizadas para abelhas nativas sem ferrão. 
O foco principal é transformar a meliponicultura urbana em um objeto de design exclusivo, promovendo a regeneração ambiental por meio da venda de kits de sementes e mudas de plantas melitófilas.

# Visão Geral do Projeto
Diferente das caixas padrão de mercado, o Bee-Hub oferece réplicas arquitetônicas detalhadas (maquetes em escala) que servem como "casca" protetora para ninhos de abelhas nativas. O modelo de negócio abrange:

Design Customizado: Réplicas de prédios, residências ou instituições (como o campus IFPR) feitas em madeira balsa e acrílico.

Bem-estar Animal: Sistema de "caixa dupla" que garante isolamento térmico e proteção contra luminosidade.

Kit de Regeneração: Venda conjunta de sementes e mudas de flores específicas para atrair polinizadores locais.

Plataforma Digital (MPV): Um aplicativo móvel desenvolvido para conectar a comunidade, catalogar dados educativos das espécies foco (Mandaçaia e Jataí) e gerenciar o fluxo de usuários.

# Materiais e Tecnologias
Para o desenvolvimento deste projeto, são utilizados:

Design & Arquitetura:

Softwares de Design: AutoCAD, Civil 3D e SketchUp para o detalhamento das fachadas e estruturas.

Materiais Físicos: Madeira balsa para a maquete externa, madeiras sustentáveis para o ninho interno e chapas de acrílico para janelas de observação não invasiva.

Logística Verde: Embalagens biodegradáveis para o envio de mudas e sementes.

Engenharia de Software (TI)
Front-end Mobile: React Native (Interface mobile enxuta, intuitiva e responsiva).
Back-end & API: Node.js (Servidor REST para persistência e processamento das requisições).
Modelagem do Sistema: Diagramas UML de Casos de Uso, Atividades e Classes.

Tecnologias e Arquitetura do MVP

O ecossistema digital foi desenvolvido focando na experiência do usuário (UX) e na validação das interfaces de navegação, utilizando:

Front-end Mobile: React Native / Expo Router (Estrutura de abas e fluxo de telas).
Back-end/Arquitetura: Node.js (Estruturação das rotas base do servidor).
Gerenciamento de Estado: Dados locais (*Mock Data*) temporários para simulação e homologação dos fluxos de cadastro e ficheiro descritivo, sem persistência em banco de dados nesta fase de validação.

Gestão do Projeto
Toda a organização de prazos e tarefas deste projeto é realizada via Trello.

Roadmap de Evolução (Próximo Semestre)

Como o foco atual foi a validação do design, usabilidade e arquitetura de rotas do aplicativo mobile, o planejamento para a Fase 3 do projeto contempla:

1. Persistência de Dados: Integração do Back-end em Node.js com um Banco de Dados Relacional (PostgreSQL/MySQL) para o cadastro real de usuários.
2. Módulo de Vendas: Implementação das tabelas e regras de negócio para venda dos kits de regeneração e caixas-maquete.
3. Mecanismo de Busca: Desenvolvimento de queries indexadas para o histórico e salvamento das pesquisas da comunidade.
